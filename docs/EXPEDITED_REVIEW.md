# Expedited Review — proposed / draft

> **Status: PROPOSED.** The tiers, donation amounts and wait times in
> this document are suggestions for Jesse to confirm. They are **not
> confirmed prices** and must not be presented as confirmed prices on a
> live site until Jesse confirms them.

Developers can speed up the review of a submitted project by making a
donation via Cash App. A donation moves the submission up the review
queue only — **it does not guarantee approval**. Every submission still
goes through the same quality and safety checks (HTTP/TLS, browser
rendering, documentation, scoring, malware/phishing/deceptive-redirect
hard fails). Draft policy: a submission that fails those checks is
**not refunded automatically**.

## How it works

1. **Submit your project** via a GitHub issue using the Submit a Project
   template, and pick an expedited-review tier in the form.
2. **Donate via Cash App:** https://cash.app/$slightlysigh
   - Free: $0 — no donation, standard queue.
   - Standard: $5 donation.
   - Priority: $15 donation.
   - Same-day: $30 donation.
3. **Email** primecomputerpieces@gmail.com with:
   - your Cash App **transaction code**,
   - the **project name**,
   - your **GitHub issue number**,
   - the tier you chose.
4. **Verification:** the transaction code is matched against the Cash
   App donation and the GitHub issue. Once matched, the submission is
   moved into the expedited queue for its tier. If the code cannot be
   verified, or the amount does not match the chosen tier, the
   submission stays in the free/standard queue until it is resolved.
5. **Review:** the project is inspected and scored as normal. The
   result — approved, corrections requested, or rejected — is posted
   on the GitHub issue, with a link to the published profile page if
   it passes.

## Tiers (proposed)

| Tier | Donation | General wait time |
| --- | --- | --- |
| Free | $0 | 10–14 days |
| Standard | $5 | 3–5 days |
| Priority | $15 | 24–48 hours |
| Same-day | $30 | Same day if submitted before 12pm ET, otherwise next day |

Wait times are general estimates, not guarantees. They run from when
the donation is verified (transaction code + issue number matched),
not from the moment the issue is opened. Weekends, holidays and a
backlog of expedited submissions can extend them. The Same-day cutoff
is 12pm ET: submit and verify before then for same-day review; after
that, review is the next day.

## What a donation does not do

- It does not guarantee approval or publication.
- It does not skip, weaken or override any inspection, scoring or
  safety check.
- It does not buy a listing, a higher quality score, or a featured
  placement.
- A failed submission is not refunded automatically (draft policy —
  confirm before going live).
